# Монтаж коротких видео Хочу-Плачу

Ролики 9:16 (1080×1920) для Shorts, Reels, TikTok и Telegram:

- вращающаяся карточка Хочу-Плачу (анимация с прозрачным фоном, `render/assets/overlay-*.webm`);
- вертикальным исходникам — карточка на 10% крупнее, без полосы;
- горизонтальным — полоса с условиями под видео;
- текст-хук поверх кадра.

## Как это работает

Монтаж запускает n8n (воркфлоу «Видео 2 — Монтаж»):

1. создаёт **черновой** релиз (его видят только владельцы репозитория) и кладёт туда исходник `source.mp4`;
2. запускает сценарий [`render.yml`](.github/workflows/render.yml) с номером релиза и параметрами монтажа;
3. ждёт, пока в релизе появятся `result.json` и `out.mp4`, забирает ролик в Google Drive и удаляет релиз.

Ключи и токены в репозитории не хранятся.

## Запуск вручную (проверка)

Releases → Draft a new release → прикрепить `source.mp4` → Save draft. Узнать ID релиза, затем
Actions → render → Run workflow, указать ID и, например, `{"hook": "Тест", "duration": 12}`.

## Параметры (`params`)

| Параметр | По умолчанию | Значения |
| --- | --- | --- |
| duration | 30 | длительность, с (5–60) |
| start | -1 | начало, с; -1 — середина исходника |
| hook | — | текст поверх кадра |
| overlay | logo | logo, nologo, png, none |
| overlay_pos | tr | tr, tl, top, br, bl |
| overlay_scale | 0.68 | размер карточки |
| overlay_mode | loop | loop — весь ролик, once — один оборот |
| banner_from | 0 | с какой секунды карточка |
| bar | auto | auto, none, static (A), ticker (B) |
| vertical_boost | 1.1 | увеличение карточки на вертикальных |

## Вариант с собственным сервером

В папке `render/` есть HTTP-сервис (`app.py`, `Dockerfile`, `install.sh`) — для VPS, если понадобится.
